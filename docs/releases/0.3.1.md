# Malapit 0.3.1 — Next steps when a property is taken

Released November 27, 2026. Public beta: https://malapit.pages.dev/.

Includes the [viewing requests and rental progress from 0.3.0](0.3.0.md). When a listing is rented, withdrawn or otherwise unavailable, inquiries now show **This property is no longer available** and **Find another place**. New viewing and rental-setup buttons are hidden. Conversation and appointment history stay accessible.

This uses the listing's current status, so republishing a property restores the viewing option. An already connected renter keeps their rental details, bill and payment links. No additional database migration or paid service is needed.

TypeScript, the production build and 173 unit tests passed. 99 isolated API checks and Chrome checks cover both the connected renter's bill and the other prospect's unavailable-property screen. Test fixtures stay local; no real rental, transfer or push message is created.
