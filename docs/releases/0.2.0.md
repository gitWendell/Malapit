# Malapit 0.2.0 — public beta

Release date: November 26, 2026 (Philippines).

Live website and installable web app: https://malapit-test.malapit-ph.workers.dev/

The existing free address is retained so current Google sign-in, accounts, listings, private rental/payment history, shared links and browser notification permissions continue on the same origin. The `test` word in the hostname is a label, not an access restriction. This release opens the existing website/PWA for public use; it does not publish a Google Play package or enable gateway payments.

## What people can use

- Browse real published rental listings on the map, starting in Cebu City. Fictional example homes are hidden by default and require an explicit preview choice.
- Sign in with Google, save homes, contact a lister and continue the conversation.
- Owners offer rental details and a first rent bill from a real inquiry. The original renter reviews and accepts, creating the private rental and first bill while marking the listing rented.
- Owners save private receiving details/QR. Renters pay the owner directly, report the payment and receive the owner's confirmation. No funds are collected, held, automatically deducted or transferred by Malapit.
- Private units, invitations, optional future monthly bills, corrections, history and owner reports remain available.
- The notification bell shows new messages, rental invitations, bills and payment updates. Phone/browser alerts are optional. Rent reminders pause for pending reports, fully paid or cancelled bills, and closed rental connections.
- Chrome on Android can install the web app from its browser menu. A branded link preview uses Malapit's existing app icon; the local install-copy fallback now points to the current live address.

## Operating the first release

Listings require the existing reviewer to approve them and owners to reconfirm availability. The free safeguards remain: 30 managed public properties, five photos per property, ten upload attempts per owner per Philippine day, and the existing storage/private-rental/bill/notification caps. Stop accepting additional properties if capacity is full; do not enable a paid plan automatically.

Contact and privacy operator: Casul Wendell, casulwendell12@gmail.com. Privacy and Terms pages describe the public beta and remain linked from the app. No new data use or paid service is introduced.

Keep onboarding focused on a small group of Cebu-area owners before broad promotion. New activity creates notifications; historical conversations are not backfilled. Owners still check their actual cash, bank or wallet records before confirming receipt.

## Verification and remaining device checks

Passed before publication: TypeScript, 157 automated tests, 91 isolated listing-to-payment/API/privacy checks, and 32 Chrome screen/interaction checks. Chrome checked 320, 390, 768 and 1440-pixel layouts, owner receiving setup, inquiry, explicit first-bill amount, rental acceptance, renter report, owner confirmation, unread notifications, permission timing and the renter’s notification-to-settled-bill link. No uncaught browser errors or horizontal page overflow were observed. All fictional browser/database fixtures were removed. No real listing, account, money or push endpoint was created in production.

Real Google sign-in was previously completed on the live origin. This release keeps that origin and provider configuration. A physical Android install/lock-screen notification test remains a user-device check; headless Chrome and service-worker tests do not prove actual phone delivery.

Supabase was ACTIVE_HEALTHY at release preparation. Its photo bucket is private, limited to 400 KiB JPEGs, with no client storage policies. Its security advisor reports one password-specific warning: leaked-password protection is disabled. Malapit accepts verified Google identities only; no password login or paid setting was added. [Supabase password-security guidance](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).

## Deploy and recover

Deploy the tested build to the existing `malapit-test` Worker with Supabase authentication, the existing D1 binding, existing runtime secrets and no R2 binding. No database migration or data deletion is required by 0.2.0. Keep release notes and source in GitHub. The previous deployed version is `4fdbc299-2439-45b0-937d-26a136edea0b` if a code rollback is needed. A Worker rollback never restores deleted data; this release does not delete records or objects.
